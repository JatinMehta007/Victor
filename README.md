## 🚀 Overview

**Victor** is a powerful and user-friendly blogging platform where users can sign up, log in, create blogs, view others' blogs, and manage their own content. It focuses on clean UI, speed, and simplicity.

## ✨ Features

- 🔐 JWT-based Authentication (Signup/Login)
- 🧾 Create, Read, Update, Delete blogs
- 👤 Profile management
- 🚀 Fast backend powered by **Hono**
- 🧩 Styled with **Tailwind CSS**
- 📦 Data managed with **Prisma + PostgreSQL**
- 🌐 Fully Responsive Design
- 🎨 Context API + Custom Hooks for state management
- 🧪 Error handling, loading states, and form validation
